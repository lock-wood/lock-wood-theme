# herdr

To use lock-wood theme in herdr, append the following config to your herdr
config file:

```
Linux and macOS: ~/.config/herdr/config.toml
Windows:          %APPDATA%\herdr\config.toml
```

```
[theme.custom]
sidebar_bg = "#242832"
active_row_bg = "#1A1C20"
selection_bg = "#254A65"
panel_bg = "reset"
accent = "#AE85AB"
green = "#759C75"
blue = "#254A65"
red = "#C08281"
yellow = "#AA9980"
```

Save the file and reload herdr config.
